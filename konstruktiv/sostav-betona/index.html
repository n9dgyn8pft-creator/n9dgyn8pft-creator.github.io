Состав бетона: пропорции цемента, песка и щебня

Расход цемента, песка, щебня и воды на 1 м³ бетона по классу, пропорции в вёдрах и на замес бетономешалки.

Состав бетона
Необязательно. Готового бетона из замеса ≈ 65% объёма барабана
Расход материалов
МатериалНа 1 м³На весь объёмВ штуках / объёме
Оговорки

Составы ориентировочные для тяжёлого бетона на песке средней крупности и гранитном щебне фракции 5–20 мм, подвижность П2–П3, без добавок. Насыпная плотность для пересчёта в объём: цемент 1,3 т/м³, песок 1,5 т/м³, щебень 1,4 т/м³. Влажный песок уже содержит воду: уменьшайте количество воды по подвижности смеси.

Для ответственных конструкций (фундаменты, перекрытия, колонны) состав подбирается лабораторией по ГОСТ 27006, а лучше брать товарный бетон с паспортом. Самозамес на глаз редко даёт класс выше B15–B20.

О расчёте

Калькулятор показывает ориентировочный состав тяжёлого бетона по классу прочности: массу материалов на 1 м³ и на весь объём, количество мешков цемента, пропорции по объёму для замеса вручную.

Как пользоваться

  1. Выберите класс бетона и марку цемента.
  2. Укажите объём бетона.
  3. При необходимости задайте объём барабана бетономешалки.

На что обратить внимание

  • Составы рассчитаны на песок средней крупности и гранитный щебень 5–20 мм без добавок.
  • Влажный песок содержит воду — уменьшайте количество воды по подвижности смеси.
  • Для фундаментов и перекрытий надёжнее заказывать товарный бетон с паспортом.

Частые вопросы

Какие пропорции для бетона B25 (М350)?

Ориентировочно Ц : П : Щ ≈ 1 : 1,5 : 3,1 по массе на цементе М500. Точный состав подбирает лаборатория.

Сколько мешков цемента на куб бетона?

Для B15 — около 5–6 мешков по 50 кг, для B25 — около 8.

Можно ли сделать B25 в бетономешалке?

Можно, но стабильно получить класс выше B15–B20 без дозирования по массе и контроля воды сложно.

Нормативы: ГОСТ 27006 — правила подбора состава бетона; ГОСТ 26633 — бетоны тяжёлые и мелкозернистые.
